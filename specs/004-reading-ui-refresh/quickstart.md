## 2. 화면 점검 (브라우저, 블로그를 켠 뒤 http://localhost:8000)

준비: 사진 두 장·소제목(##·###) 여러 개·코드 블록(```python)·표가 있는 글 하나, 같은 카테고리 글 두세 개(하나는 사진 없이).
화면 모드 버튼으로 라이트·다크를, 브라우저 창을 좁혀(또는 개발자 도구 375px) 휴대폰 폭을 함께 본다.

| # | 할 일 | 기대 |
| --- | --- | --- |
| 1 | 블로그 홈·내 블로그 열기 | 한 줄에 글 하나, 사진 있는 글은 오른쪽 정사각형 사진, 굵은 테두리·진한 그림자 없음 |
| 2 | 375px로 좁히기 | 사진 84px, 날짜·댓글·조회 줄이 사진 아래까지 한 줄, 가로 스크롤 없음 |
| 3 | 사진이 있는 글 열기 | 날짜 옆 "N분 읽기", 본문 위 "목차 N" |
| 4 | 목차 항목 누르기 | 그 소제목이 위쪽 메뉴 바로 아래로 이동, 주소창은 `#/post/번호` 그대로, 뒤로 가기 한 번이면 이전 화면 |
| 5 | 아래로 내리기 | 맨 위 주황 막대가 차오름, 한 화면 넘게 내리면 오른쪽 아래 ↑ 버튼 → 누르면 맨 위 |
| 6 | 본문 사진 누르기 | 어두운 배경에 크게, Esc·바깥·✕로 닫힘, Tab으로 사진에 가서 Enter로도 열림 |
| 7 | 코드 블록 '복사' | '복사했어요'로 바뀌고 붙여넣으면 코드 그대로, 위에 언어 이름(Python) |
| 8 | '공유하기' | 휴대폰·Safari는 공유 창, PC 크롬 등은 "주소를 복사했어요" |
| 9 | 글 아래 | 작성자 카드(이웃 추가·블로그 가기), 같은 카테고리 다른 글 최대 4개 사진 카드, 이전·다음 글 카드 |
| 10 | 375px에서 긴 코드·넓은 표가 있는 글 | 페이지는 옆으로 안 밀리고 코드·표 안에서만 밀림, 표 글자가 한 글자씩 끊기지 않음 |
| 11 | 다른 화면으로 이동 | 막대·↑ 버튼 사라짐 |
| 12 | 회원 로그인·가입 화면(8080) | 블로그와 같은 얇은 선·둥근 카드 |
| 13 | 기기 '동작 줄이기' 켜고 4·5 반복 | 부드러운 이동 없이 바로 이동 |

## 3. 기존 데이터

- 기존 blog.db 그대로 서버를 켜고 글·댓글·공감·이웃 수가 그대로인지 본다(스키마 변경 없음).
- 브라우저가 예전 화면을 보이면 새로 고침(화면 파일 버전 `style.css?v=19`, `app.js?v=20`, 회원 `style.css?v=4`).
