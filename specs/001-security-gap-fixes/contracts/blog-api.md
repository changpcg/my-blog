# Contract: 블로그 서버 API 변경 (server.py)

## DELETE /api/comments/{id}

**요청 본문** (방문자 댓글일 때만 필요)

```json
{ "password": "작성할 때 넣은 비밀번호" }
```

| 상황 | 상태 | 응답 |
| --- | --- | --- |
| 주소에 `password=` 가 있음 | 400 | `{"error": "비밀번호는 주소에 넣을 수 없어요. 화면을 새로 고친 뒤 다시 시도해 주세요."}` (비밀번호 확인 안 함, 실패로 세지 않음) |
| 댓글 없음·이미 삭제됨 | 404 | `{"error": "댓글을 찾을 수 없어요."}` (실패로 세지 않음) |
| 관리자·블로그 주인·회원 작성자 | 200 | `{"ok": true}` (잠금 무시) |
| 잠김 | 429 | `{"error": "비밀번호를 여러 번 틀렸어요. N분 뒤에 다시 시도해 주세요."}` |
| 비밀번호 틀림 | 403 | `{"error": "비밀번호가 맞지 않아요."}` (0.5초 이상 지연, 실패 기록) |
| 비밀번호 맞음 | 200 | `{"ok": true}` (그 댓글 실패 기록 삭제) |

## POST /api/logout

**응답** (항상 200, 블로그 세션 쿠키 삭제)

```json
{
  "ok": true,
  "auth_url": "http://localhost:8080",
  "auth_logout": { "action": "http://localhost:8080/sso_logout.php", "t": "<로그아웃 표>" }
}
```

- `auth_logout`은 로그인한 사용자가 회원 서버와 연결된 계정(`auth_uid` 있음)이고 sso.key를 읽을 수
  있을 때만 객체, 그 밖에는 `null`.
- 예전 필드 `auth_logout_url`은 없앤다(표가 주소에 실리지 않게).

## DELETE /api/users/{id} (관리자)

요청·응답 형식은 그대로. 처리 결과만 바뀜: 탈퇴 회원의 댓글 중 남의 답글이 남는 것은 "삭제된 댓글" 자리로
남고, 그 회원의 답글은 지워진다(data-model.md 상태 전이).
