# Quickstart: 블로그 꾸미기 점검

1. 블로그를 켜고(`start-blog.command`) 관리자로 로그인 → 블로그 관리 → 🎨 꾸미기.
2. '파랑'을 누르면 미리보기만 파랑 → 저장 → '내 블로그에서 보기 →': 글쓰기 버튼·선택된 '전체' 칩·태그 hover가 파랑.
3. 내 글 하나를 열어 파랑인지, 블로그 홈(🏠)으로 가면 코랄로 돌아오는지, 다른 회원 블로그는 그 사람 색인지 본다.
4. 화면 모드 버튼으로 다크 → 같은 계열의 밝은 파랑, 글쓰기 버튼 글자는 어두운 색.
5. 블로그 사이드바와 블로그 홈 사이드바에 '인기 글'(조회수 순 5개)이 보이는지. 비공개 글은 빠진다.
6. 꾸미기에서 '방문자 수'·'미니룸'을 끄고 저장 → 로그아웃 후 내 블로그: 방문자 칸·미니룸 없음.
7. `python3 tests/smoke_blog_design.py` → OK.
